# IgY-RIG | ผลการประเมินความเป็นไปได้ในการลงทุนเบื้องต้น

**เอกสารประกอบข้อ 7 ของข้อเสนอโครงการขอรับทุน | พฤศจิกายน 2569**

โครงการพัฒนาอิมมูโนโกลบูลินจากไข่ไก่เพื่อป้องกันโรคพิษสุนัขบ้า (IgY-RIG) ได้จัดทำแบบจำลองทางการเงินเพื่อประเมินต้นทุนการผลิต ความเป็นไปได้ในการลงทุนระบบการผลิตตามมาตรฐาน GMP และปัจจัยที่มีผลต่อความสำเร็จของโครงการ เอกสารนี้นำเสนอวิธีคำนวณ สมมติฐาน ผลการวิเคราะห์ และความไม่แน่นอนอย่างโปร่งใส เพื่อสนับสนุนการพิจารณาของผู้ให้ทุน

## เอกสารประกอบ

- [ภาคผนวกวิธีวิเคราะห์และผลประเมิน](technical_appendix_th.md) — ที่มาของข้อมูล สมมติฐาน สูตรคำนวณ ผลลัพธ์ และแผนลดความไม่แน่นอน
- [R code สำหรับตรวจสอบผลคำนวณ](reproduce_results.R) — สามารถรันด้วย base R เพื่อคำนวณ NPV, IRR, PI และกรณีทดสอบข้อจำกัดด้านตลาด

## สรุปผลการประเมิน

| ตัวชี้วัด | กรณีฐาน CT (ปรับหน่วยต้นทุน) | กรณีขยายกำลังผลิต |
|---|---:|---:|
| เงินลงทุน GMP | 150 ล้านบาท | 450 ล้านบาท |
| NPV | −76.51 ล้านบาท | +38.59 ล้านบาท |
| IRR | −3.97% | 5.72% |
| PI | 0.49 | 1.09 |
| ระยะเวลาประเมิน | 10 ปี | 20 ปี |

กรณีฐานยังไม่แสดงผลตอบแทนทางการเงินเป็นบวกภายใต้สมมติฐานปัจจุบัน ส่วนกรณีขยายกำลังผลิตให้ผลตอบแทนเป็นบวกเล็กน้อย แต่ต้องอาศัยการขายตามเป้าหมายและมีระยะเวลาประเมินต่างกัน ผลทั้งสองกรณีจึงใช้สำรวจเงื่อนไขการลงทุน ไม่ใช่การจัดอันดับทางเลือกภายใต้ฐานเดียวกัน

## ขอบเขตการประเมิน

ผลที่นำเสนอเป็น **การวิเคราะห์ความเป็นไปได้ทางการเงินเบื้องต้น** มิใช่ผลการประเมินอัตราส่วนผลประโยชน์ต่อต้นทุนทางสังคม (social B/C ratio) หรือการวิเคราะห์ต้นทุนประสิทธิผล (cost-effectiveness) เนื่องจากยังไม่มีข้อมูลผลลัพธ์สุขภาพและต้นทุนเปรียบเทียบเพียงพอ การวิเคราะห์ระยะต่อไปจะพิจารณาประเด็นดังกล่าวเมื่อมีหลักฐานที่เหมาะสม

## ที่มาของข้อมูล

- `IgY_RIG_Early_HTA_Working_Model_CT.xlsx` — แท็บ `HTA Model Inputs CT` และ `HTA Cost and Investment CT`
- `IgY_RIG_parameters_2026-11-01_a.csv` และ `IgY_RIG_parameters_2026-11-01_b.csv` — สมมติฐานกรณีขยายกำลังผลิต
- ข้อมูลเฝ้าระวังที่ได้รับ ณ 29 ตุลาคม 2569 — ผู้สัมผัสสัตว์ 1,451,921 ราย; ผู้ต้องรับวัคซีน 702,567 ราย; จำนวน 594,928 รายที่รายงานว่ามีข้อบ่งชี้รับ RIG (84.68%) ซึ่งอยู่ระหว่างการตรวจสอบนิยามกับแหล่งข้อมูลต้นทาง

ข้อมูลต้นฉบับไม่ได้เผยแพร่ใน repository นี้ เนื่องจากการเผยแพร่ขึ้นอยู่กับสิทธิและการอนุญาตของเจ้าของข้อมูล ข้อมูลและสมมติฐานที่ใช้คำนวณถูกระบุในภาคผนวกและ R code เพื่อให้สามารถตรวจสอบผลได้
